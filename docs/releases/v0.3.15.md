# Template v0.3.15 — explicit lifecycle onboarding

This starter pins go-workflow-stack v0.3.26 at
`b2d235610691eead011cc738f278887a99e4bbe0`. Model/effort, version source,
release destination, checks, base/workspace and phase proof settings are explicit
onboarding inputs. There is no execution_defaults or automatically chosen model.

Ordinary pinned runtime checkouts and linked worktrees are accepted. Dirty or
mismatched explicit runtimes are preserved and rejected. Source maintenance stays
separate from the reusable smoke and is archived as non-executable history.

Validation covers schema-valid examples, project customization dropping source
metadata, task intake, ordinary/linked exact launchers, wrong-ref/dirty preservation,
and the existing template pairing check. Full two-release clone/worktree lifecycle
proof follows in abc-template-02. Live worker proof is the separately published
stack v0.3.26 evidence; these onboarding checks make no model calls.

No GitHub Actions, global skill installation or production deployment. Rollback
uses a new template release or a previous immutable pin; no published tag rewrite.
