# v0.3.19 — verified bounded serial autonomy onboarding

This release pins `go-workflow-stack` v0.3.43 and makes its bounded serial
campaign contract discoverable from a fresh template clone. Projects still
choose their own goal, supported model profiles, cumulative budget, release
authority and deployment boundary; the starter contains no active defaults.

The new local fixture clones the committed starter, exercises read-only guided
onboarding, rejects missing release authority before worker execution, and then
uses one controller to complete two separately released tasks plus a grounded
goal audit. It uses deterministic worker doubles and a local bare Git remote.

The stack separately preserves a measured native-Codex synthetic proof with an
automatic interruption and resume. Neither proof claims eight-hour unattended
reliability, hosted publication, production deployment or broad model quality.
