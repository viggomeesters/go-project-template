# v0.3.18 — mandatory root AGENTS.md gateway

The template now carries the exact-case root `AGENTS.md` gateway required by
stack v0.3.39. The bounded managed block points agents into repository-local
`.go` state and its validate/status/router, scoped execution, evidence,
critic/repair and completion lifecycle. Existing template-specific onboarding,
release and GitHub Actions restrictions remain intact outside the block.

Fresh copies validate without a repair step. Existing projects can preview and
apply the same bounded change with:

```bash
go-workflow agents sync . --apply
```
